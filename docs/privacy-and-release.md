# 数据与许可边界

Zotero是文献、PDF、笔记和批注真值；工作台不建立第二份权威文库，不新增账号或遥测。Zotero本机端口不应向外网暴露。

文库/PDF普通浏览不启动模型。加入上下文和提问会把选定材料交给当前宿主Agent。研究页默认开启外文高亮/下划线中文对照：仅对用户明确选择且已经载入的研究范围逐批处理，每批最多20条；可以关闭，失败不自动重试。阅读者备注和独立笔记不进入自动翻译。

点击全文翻译或TextFold，会把相应PDF的完整可提取文字交给已经配置的Codex CLI阅读模型，消耗该模型额度；不能把“本地工作台”宣传为任何操作下全文都不出机。模型不可用不会转投另一服务。可选阅读模型覆盖只作用于后台任务，不改全局Codex配置或登录凭据。

译文和AI导读均为派生阅读辅助，原文、页码、来源key及指纹独立保留。它们不自动取得humanSelected身份，也不自动进入写作语料或写回Zotero。来源无法重新核验时隐藏旧译文，但不销毁成功快照。

DOI/arXiv识别发送标识符给相应元数据服务；语义检索、easyScholar等可选功能遵循各自已配置服务的数据流。操作台账、协作及研究缓存仅在本机私有状态目录，缓存可含原文与模型结果，不要上传Git。未知写入先核对，不能删除台账后盲重试。

工作台与固定ZCode上游保留MIT；TextFold保留Apache-2.0 LICENSE/NOTICE；PDF.js与内置Node保留第三方许可。PyMuPDF等可选依赖适用各自许可，不随基础包分发。本项目不为任意闭源组合提供商业许可保证。

1.x仍为开源预览。代码、单元/协议测试、实际模型调用、受控浏览器和正式宿主验收分别记录。Windows等构建目标不等于真机通过；不以DSH成功代表Codex，也不以文库可读代表双向写回。

TextFold还需可选Python环境与Poppler。翻译不依赖Python或额外Zotero MCP；缺少Poppler时仅对通过检查的PDF.js逐页文字回退，缺失/扫描/明显乱码拒绝冒充全文。本版不提供OCR或重排译文PDF。
