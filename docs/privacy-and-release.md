# 数据与许可边界

文库、PDF和笔记来自本机Zotero，不建立第二份权威文库，不新增账户或遥测。Zotero通信端口不应向外网暴露。

用户加入AI上下文或发送提问后，选定材料进入当前宿主模型；DOI/arXiv识别向元数据服务发送标识符。可选语义检索、easyScholar在线期刊查询、TextFold任务遵循各自已配置服务的数据流和额度。不能把“本地工作台”宣传为任何操作下全文永不出机。

操作台账、协作与研究缓存仅保存在使用者本机私有状态目录；研究缓存可包含原文、标注与模型结果，不要上传Git。未知写入的台账应先核对，不删除后盲重试。

工作台和固定ZCode上游保留MIT许可；TextFold保留Apache-2.0 LICENSE/NOTICE；PDF.js第三方声明和内置Node许可随包分发。可选Python依赖PyMuPDF适用其自身AGPL/商业许可，不随基础便携包分发。本项目不提供法律判断或任意闭源组合的商业许可承诺。

1.0.0为开源预览：原版工具和资源入口的保留不等于所有平台、PDF及写入场景均已真机通过。发布说明明确已验证和未验证部分，商业与全平台稳定性尚未背书。
