# Zotero Workbench 1.0.0

**开源预览版。** Zotero Workbench 把文献浏览、PDF 阅读、批注、引用和研究工作流放进 Codex 面板。Zotero 仍是文献与批注的唯一数据源。

## 开始使用

安装 Zotero 桌面版和 Codex 中的 Zotero Workbench 插件，然后在 Zotero 设置中启用本机应用访问。核心文库功能通过 Zotero Local API 工作；Zotero 10 可直接使用笔记、元数据修改、单条文献导入和阅读高亮写入，无需另装独立 Zotero MCP 服务。导出引用和书目也在工作台本地完成。

Zotero 写入需要在 Zotero 中批准权限。工作台的标准操作先显示预览，再由用户确认，并以操作记录和写后回读核对结果。Zotero 9 的本地 API 是只读的；如果本机已有兼容的旧版 Zotero MCP 写入服务，工作台可在预览时标明并使用该兼容通道。没有兼容服务时，Zotero 9 上的标准写入功能不可用。

原版工具中仍保留直接写入能力，例如添加带 PDF 的条目、附件、独立笔记、集合以及批量维护元数据。它们使用 Zotero 自己的授权对话框，但不经过工作台新增的预览与事务台账。调用这些直接工具时，请在 Zotero 和 Codex 中核对具体操作。

## 可选能力

- **TextFold 与标注写作**：需要 Python 3、本机已登录的 Codex CLI，并按研究功能说明运行 `python3 scripts/setup-research.py`。模型调用使用本机 Codex CLI 配置，可能消耗相应账户额度；此依赖不影响文库浏览、PDF 阅读或普通写入。
- **语义检索**：依赖可选的上游研究服务和可用额度。不可用时，普通文库搜索、全文读取、引用与导出仍可使用。
- **AI 证据高亮**：须经过 zotero-lattics 审计流程。它与用户在 PDF 中自行创建的普通高亮分开处理；审计写入仍依赖兼容的 Zotero MCP 服务。

## 预览版状态

目前的正式验收范围为 **macOS arm64**。Windows、Linux 和其他处理器架构尚未验收。1.0.0 的完整自动测试、干净环境安装与冷启动、以及 Codex/DSH/ZCode 三端真实宿主回归仍待补验；版本号升级不代表这些项目已经通过。

本版保留原版 ZCode 的 21 个 MCP 工具和 10 个资源，并在其上增加工作台功能。工具与界面的源码对照见 [原版功能对照](upstream-parity.md)。开源预览不等于所有原版工具、Zotero 版本和宿主组合均已完成端到端验收。
