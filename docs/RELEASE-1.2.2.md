# 1.2.2 标题与摘要双语（开源预览）

文献列表提供单条“翻译标题与摘要”；打开外文详情或右详情栏时默认呈现原文与中文对照。翻译沿用本机已配置阅读模型，仅处理当前条目的标题与摘要，不要求 PDF，也不会发送高亮或笔记。

中文字段保持原文，缺失摘要不会由模型补写。译文为本机可再生成缓存，不覆盖 Zotero 原始字段；来源字段变化时重新核验，失败保留原文并允许显式重试。列表不会自动批量翻译搜索结果。显示时清理标题中的格式标签，不把元数据当 HTML 执行。

原有 PDF、高亮与备注、独立笔记、期刊等级 Pill、多选、上下文、全文翻译和 TextFold 功能继续保留。各宿主源码、实际点击和正式宿主验收分别记录。
