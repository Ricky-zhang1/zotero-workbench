# 1.1.0 阅读器交互更新（开源预览）

高亮移除改为一次明确点击，后台完成版本预检与写后核对，成功后可按原key撤销；不再增加工作台二次确认。Zotero自己的写入授权仍由其管理。

右批注栏支持勾选、全选、复制、累计加入上下文和可恢复批量移除。每条操作保留独立结果，未知写入不自动重发；恢复列表读取既有磁盘journal，widget state仅为缓存，重启后不只剩最后一条记录。

新增研究背景/研究方法/研究结论/概念界定等预设，颜色与文字共同显示；显式类型写入Zotero annotation tags，不覆盖阅读者备注，也不根据旧颜色猜类型。重复命中已有高亮不擅自改标签。

研究范围可选分类或搜索文献，取消保留原选择，陈旧请求不覆盖新范围；首次连接状态会自动更新。Zotero链接通过限定协议白名单交给系统打开，macOS/Linux可用，Windows此本机打开路径尚未支持。返回成功仅表示系统接受请求。

验证：主程序227项、DSH兼容62项、便携打包6项检查通过。受控浏览器使用真实Zotero只读数据实际点击了勾选、复制按钮、范围搜索与三条批注累计材料，协作区保留3卡片。测试宿主拦截所有Zotero写入、AI调用和真实会话发送，不能当作正式Codex宿主验收；系统剪贴板内容未独立核实。本机打开工具收到系统接受回执，但Mac锁屏使原生视觉跳转和本轮新批量真实写入未验收。

便携包内置官方Node24.22.2。Windows包仅构建/校验，未真机；TextFold仍需Python、Codex CLI和Poppler等可选依赖。继续保持预发布状态，不宣称全平台免配置。
