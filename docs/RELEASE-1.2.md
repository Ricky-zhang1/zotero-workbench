# 1.2.0 研究精读与中文对照（开源预览）

TextFold保留五层，新增面向社科研究的研究问题、论证、概念、方法与证据、发现与边界、文献对话导读。作者主张与研究者提示分开；每条依据核对原文页码与连续引句，材料不足显示缺口，不把AI概括变成人工所选语料。

每篇可一键生成逐页全文中文翻译，切换原文/中文/对照并回原PDF；复制带页码的译文Markdown。本版不重排导出译文PDF。外文高亮/下划线默认自动中文对照，在显式选定且加载的范围内每批最多20条串行继续，可停止；备注、独立笔记不自动翻译。失败不自动重试。

研究材料可按文献、颜色、材料类型或显式研究类型分组，原文/批注/阅读者备注/独立笔记分块。阅读PDF后重读来源，只恢复指纹相同的选择与分组。最近任务可切回已有TextFold/译文，不重新生成。来源无法核验时隐藏旧译文，保留成功快照供重连核验。

翻译由纯Node调用已配置Codex CLI，不需Python或额外Zotero MCP。TextFold仍需其锁定Python环境及Poppler；全文当前限1–200页、16万字符。翻译仅在Poppler缺失时使用通过检查的PDF.js文字，扫描或缺页拒绝冒充全文。可选阅读模型覆盖只作用于后台子进程，不改全局Codex配置、账号或服务。

主代理独立检查：主程序262项、DSH兼容62项、Python worker8项、便携打包6项通过；浅/深测试宿主自检通过。实际调用使用虚构资料，全文翻译、高亮翻译、单页TextFold及两页社科导读均完成；两页全部引句通过原文页码核验。受控浏览器实际点击了分组、回PDF、选择恢复、自动对照、全文译文、TextFold导读与已保存结果切换，并检查浅深色/520px窄栏。本轮Zotero写入0次。

边界：受控浏览器加载真实构建与真实本机Zotero只读数据，**不是正式Codex宿主**；其上下文消息只在本地捕获。当前运行会话仍可能是旧版，不能把部署当成激活。新版正式宿主的批量删除/恢复与真实会话送达尚未验收；Windows只构建校验，DSH新版完整原生UI未验收。剪贴板按钮流程已点击，系统剪贴板内容未独立核实。1.2继续作为prerelease，不宣称全平台商业稳定。

文库/PDF浏览仍在本机；研究页自动对照与全文AI任务会发送对应内容给已配置模型，请看README和隐私说明，勿把本地缓存等同于模型不出机。包不含私人文库、研究缓存、验收材料或模型凭据。
