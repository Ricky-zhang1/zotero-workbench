# 1.2.1 高亮阅读笔记（开源预览）

阅读器中的既有 Zotero 批注提供“添加笔记”或“编辑笔记”。编辑器在当前阅读位置展开，保存后写回原批注的 `annotationComment`，与原文摘录分开显示；不新建重复高亮或第二份权威笔记。

编辑前读取最新备注和版本；保存绑定该次读取、Zotero 实例与版本。只更新备注，保留批注身份、原文、颜色、标签和位置。保存无需第二层确认；并发修改会保留草稿并提示核对。写入结果不明时不会自动重发，须先只读核对。

原有独立笔记、全文翻译、TextFold、期刊等级、删除恢复及上下文入口继续保留。Codex 和 DSH 的笔记编辑复用同一 Zotero 写回能力；它们的界面与正式宿主验收分别记录。

实现、测试和宿主激活状态以本次维护记录为准，不将编译成功或测试浏览器等同于正式 Codex 激活。

首次写入仍受 Zotero 原生授权控制。只有 Zotero 明确返回 remember=true 时才会将本插件授权存入私有状态目录；Codex 与 DSH 共用该路径，临时授权不会持久保存。
